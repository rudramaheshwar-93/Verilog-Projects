# Ripple Carry Adder

An N-bit ripple carry adder implemented in Verilog using cascaded full adder modules.

## Features
- Parameterized bit width
- Carry propagation across stages
- Full adder as base module

## Files
- `ripple_adder.v` — RTL design
- `ripple_adder_tb.v` — Testbench

## Simulation
Simulated using Xilinx Vivado. Testbench verifies sum and carry-out for multiple input combinations.
