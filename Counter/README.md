# Counter

A Verilog implementation of a binary counter that increments sequentially on each clock pulse. Operation is verified through simulation.

## Inputs / Outputs

- Inputs: CLK, RST  
- Outputs: Q  

## Files

- `counter.v` — RTL design  
- `counter_tb.v` — Testbench  

## Simulation

Simulated using Xilinx Vivado. Waveforms verify correct counting sequence and reset behaviour.
