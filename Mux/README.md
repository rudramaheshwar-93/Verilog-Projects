# 4:1 Multiplexer

A Verilog implementation of a 4-to-1 Multiplexer that selects one of four inputs based on select lines. All input combinations are verified through simulation.

## Inputs / Outputs

- Inputs: I0, I1, I2, I3, S0, S1  
- Outputs: Y  

## Files

- `mux.v` — RTL design  
- `mux_tb.v` — Testbench  

## Simulation

Simulated using Xilinx Vivado. Waveforms verify correct selection of inputs based on select lines.
