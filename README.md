# Verilog Projects

This repository contains digital design projects written in Verilog HDL, implemented and simulated using Xilinx Vivado. Each project folder includes the RTL design, testbench, and simulation waveforms.

## Projects

| Folder | Description | Status |
|--------|-------------|--------|
| FIR_Filter/ | 16-tap low-pass FIR filter, pipelined, 100 MHz | Done |
| JK_FF/ | JK Flip-Flop with all input combinations verified | Done |
| Ripple_Adder/ | N-bit ripple carry adder with carry propagation | Done |
| SR_FF/ | SR Flip-Flop with forbidden state handling | Done |
| Sequence_Detector/ | FSM-based sequence detector (e.g., "1011") | Done |
| Half_Adder/ | Basic 1-bit half adder | Done |
| Counter/ | N-bit synchronous up/down counter | Done |
| Mux/ | N-bit, 2-to-1 multiplexer | Done |

## What's inside each project folder

- RTL design file (.v)
- Testbench (_tb.v)
- Simulation waveforms (typically .wcfg or screenshot images)

## Tools Used

- Xilinx Vivado (for simulation and potential synthesis/implementation)
- Verilog HDL

## About

These projects are part of my learning journey in digital design and FPGA development. I am currently exploring RTL design, sequential/combinational circuits, Digital Signal Processing (DSP) concepts, and hardware description languages. My focus areas include understanding the intricacies of synchronous and asynchronous logic, state machine design, arithmetic circuits, and data path implementations. These examples serve as practical exercises to solidify theoretical knowledge and gain hands-on experience with Verilog and FPGA development flows.
