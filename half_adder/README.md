# Half Adder

A Verilog implementation of a Half Adder with all input combinations (00, 01, 10, 11) verified through simulation.

## Inputs / Outputs

- Inputs: A, B  
- Outputs: SUM, CARRY  

## Files

- `half_adder.v` — RTL design  
- `half_adder_tb.v` — Testbench  

## Simulation

Simulated using Xilinx Vivado. Waveforms verify correct sum and carry generation for all input combinations.
